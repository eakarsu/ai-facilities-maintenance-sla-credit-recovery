# Facilities Maintenance SLA Credit Recovery

Calculate and recover service credits for missed response, resolution, uptime, and preventive-maintenance obligations.

**Primary buyer:** Multi-site enterprises and property managers. **Evidence:** facilities contracts, assets, work orders, response times, completion evidence, uptime, preventive maintenance, invoices, SLA credits, and payments.

Full local application built with React, Vite, Express, PostgreSQL, and OpenRouter. Includes 15 domain-specific capabilities, 105 custom AI workbench fields, three scenario-fill controls per feature, operational registers, workflow transitions, analytics, professional AI decision briefs, audit history, and at least 15 PostgreSQL records per capability.

## Domain capabilities

- Vendor contract library
- Location asset registry
- Work order ingestion
- Priority classification
- Response time calculation
- Resolution time calculation
- Uptime calculation
- Preventive maintenance compliance
- Repeat failure detection
- Exclusion validation
- SLA credit calculation
- Vendor claim package
- Dispute workflow
- Invoice credit reconciliation
- Location vendor analytics

Run `./start.sh`, then open <http://127.0.0.1:4722>. API: `5722`.

Administrator: `runtime-admin@example.com` / `LocalDemo!2026`. Operator and reviewer credential buttons are available on the login page.
